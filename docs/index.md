# LLM-finetuning 学习笔记仓库

这里是我个人关于大模型后训练（Post-Training）方向的学习记录，用于沉淀、整理和复盘技术知识，内容包含理论推导、算法原理、代码实践、踩坑总结。

> 说明：本仓库仅为个人学习存档，内容仅供自己回顾，不保证完全严谨，持续更新中。

## 📚 学习范围
- SFT 监督微调
- GRPO、RLHF 等偏好对齐算法
- 大模型后训练基础理论
- 数据集构造、评估方案、工程实践
- 相关论文阅读与要点梳理

## 📖 导航
左侧菜单栏可以直接跳转各个专题笔记。

## ✏️ 维护说明
- 新增笔记：在 `docs/` 下新建 `.md` 文件
- 显示到侧边栏：在 `mkdocs.yml` 的 `nav` 配置中添加对应条目
- 提交代码后，GitHub Actions 会自动构建并更新网页

## 📌 格式支持
- Markdown 基础语法
- LaTeX 数学公式：`$单行公式$` / `$$多行公式$$`
- 代码块高亮（Python、Shell 等）
