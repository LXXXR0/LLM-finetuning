# MCD 大模型微调项目 — 完整学习路径

## 项目简介

本项目是麦当劳中国 AI 团队的大模型微调 pipeline，核心目标：
1. 将 MCD 内部知识注入大语言模型（知识续训）
2. 训练模型完成智能 Agent 选择与排序任务（能力对齐）
3. 通过强化学习进一步优化决策能力（策略优化）

技术栈：Qwen3 系列模型 + Unsloth + LoRA + GRPO + vLLM

### 二、`continue_pretrain/` — 知识续训模块

**执行流水线：**

```
① prepare_pretrain_data.py  →  ② continue_pretrain.py  →  ③ pretrain_eval.py
                                                              ↓
④ prepare_sft_data.py  →  ⑤ split_sft_data.py  →  ⑥ sft_train.py  →  ⑦ sft_eval.py / llm_eval.py
```

| 序号 | 文件 | 作用 | 输入 → 输出 |
|------|------|------|-------------|
| ① | `prepare_pretrain_data.py` | MD 文档 → JSONL，按 token 长度分桶 | `./data/*.md` → `pretrain_data/` |
| ② | `continue_pretrain.py` | 分阶段续训（2k→4k→8k→64k） | `pretrain_data/` → `pretrain_lora_model/` |
| ③ | `pretrain_eval.py` | 知识召回评估（续写测试） | `pretrain_lora_model/` → 评估指标 |
| ④ | `prepare_sft_data.py` | 用 LLM 从文档生成 QA 对 | `./data/*.md` → `sft_data.jsonl` |
| ⑤ | `split_sft_data.py` | 拆分训练/验证集（80:20） | `sft_data.jsonl` → `train/val` |
| ⑥ | `sft_train.py` | 在续训模型上做 QA 微调 | `pretrain_lora_model/` → `sft_lora_model/` |
| ⑦ | `sft_eval.py` | 评估 SFT 模型 | `sft_lora_model/` → 评估结果 |
| — | `llm_eval.py` | Agent 路由评估 | 同上 |
| — | `s3_utils.py` | S3 上传/下载工具 | 被其他脚本 import |
| — | `continue_pretrain.sh` | 启动 DDP 训练的 shell 脚本 | 调用 ② |
| — | `predata_process.sh` | 启动数据处理的 shell 脚本 | 调用 ① |

## 💡 学习建议

1. **先跑通阶段一**，确保你能理解一个完整的训练脚本
2. 每个阶段的 ⭐ 文件是核心，其他是辅助
3. 遇到不懂的概念（LoRA、GRPO、vLLM 等），及时查阅或提问
4. 建议边看代码边画数据流图，帮助理解文件间的关系
5. 各模块的 `s3_utils.py` 代码几乎一样，看一次就够了
6. `text/` 模块是早期版本，可以快速浏览了解演进历史

## 🔑 核心概念速查

| 概念 | 一句话解释 |
|------|-----------|
| SFT | 监督微调，给模型看"正确答案"让它模仿 |
| LoRA | 只改模型一小部分参数的省显存微调方法 |
| Continue Pretrain | 在预训练基础上继续用新文档训练，灌入新知识 |
| GRPO | 一种强化学习算法，让模型通过"试错+奖励"学习 |
| vLLM | 高性能推理引擎，加速模型生成 |
| Unsloth | 训练加速框架，2x 速度提升 |
| OPSD | 在线策略自蒸馏，用教师模型指导学生模型 |
| 4-bit 量化 | 把模型参数压缩到 4 位，大幅减少显存占用 |
| Agent | 处理特定类型问题的 AI 模块 |
| 置信度 (conf) | 模型对某个 Agent 适合回答该问题的把握程度 |
