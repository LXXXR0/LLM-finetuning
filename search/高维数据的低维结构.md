# High‑Dimensional Data Analysis with Low‑Dimensional Models

> 作者：John Wright、马毅（Yi Ma），剑桥出版社预印本。
> 现实世界数据看着维度极高（图片、基因、视频），但数据本身藏着低维结构（稀疏、低秩）。
> 全文三大部分：原理Part I、计算Part II、应用Part III，最后尾声还把这套理论和深度学习/神经网络（MCR²、ReduNet）打通。

## 一、时代背景：从“数据少”到“数据爆炸”
1. 数据 >> 信息
2. 数据 = 有用信息 + 大量无关垃圾
3. 不完整数据 ≈ 完整信息

比如Netflix电影评分矩阵，大量用户没看过很多电影，矩阵大量空缺；但人的喜好有很强相关性，矩阵内在秩很低，可以补全缺失评分（协同过滤）

> 核心矛盾：我们拿到的是高维原始数据，但真正的知识藏在底层低维结构中。
> 本书：（1）数学上搞清楚：什么条件下，能从高维脏数据还原底层低维结构（非渐近，给具体样本复杂度）；（2）工程上：怎么写扩展算法，大规模算出来。

### 现实世界低维结构两大主角
- 1. 稀疏 Sparse：一个向量绝大多数元素等于0，只有少数非零；
- 2. 低秩 Low-rank：矩阵的列都挤在一个很小的线性子空间。

## Part I：原理篇：稀疏、低秩模型的数学道理
### 1. 稀疏信号模型
问题：有方程 $y=Ax$
$A$ 是测量矩阵，$y$ 是观测，**未知数 $n$ 远大于观测 $m$（欠定方程组）**，有无穷多解。但真实的 $x$ 是稀疏的（大部分是0），我们希望将真实 $x$ 找出来。

#### 1. $\ell_0$ 范数：统计向量非零元素的个数
$\|x\|_0$ = 多少个位置不等于 0。
目标：$\min \|x\|_0,\; \text{s.t.}\; Ax=y$，找满足方程最稀疏的 $x$。

#### 2. 凸松弛：用 $\boldsymbol{\ell_1}$ 范数代替 $\ell_0$
$$\|x\|_1=\sum |x_i|$$
绝对值之和。

$\boldsymbol{\ell_1}$ 是 $\ell_0$ 的 **凸包（Convex Envelope）**，凸优化，多项式时间可以求解
> 关键问题：$\boldsymbol{\ell_1}$ 最小化什么时候可以等价于 $\ell_0$，正确恢复真正稀疏解？

书中给几何图像：
- 系数空间：不断放大 $\boldsymbol{\ell_1}$ 菱形几何体，第一次碰到可行解集合，接触点天然出现在顶点，顶点对应稀疏向量。
- 观测空间：矩阵 $A$ 把菱形投影成多面体。
> 但是不是永远成功？有条件。

### 2. 稀疏恢复的凸方法：什么时候 $\boldsymbol{\ell_1}$ 能成功恢复信号？
两个核心判据，告诉你：什么样的 $A$ 矩阵，$\boldsymbol{\ell_1}$ 最小化可以完美找回稀疏 $x$。

（1）互相干性 Mutual Coherence $\boldsymbol{\mu}(A)$：矩阵不同两列之间最大内积。列越接近正交，$\boldsymbol{\mu}$ 越小，越容易恢复稀疏信号。
（2）RIP（受限等距性质）：随机高斯矩阵满足RIP。只要 $\boldsymbol x$ 足够稀疏，$\boldsymbol{\ell_1}$ 就能恢复。

还有非常重要的现象：相变 Phase Transition。
固定矩阵 $A$，随着真实信号非零元 $k$ 慢慢变大：
- $k$ 比较小：100%可以正确恢复；
- $k$ 超过某个阈值，成功率断崖跌到0。

高维几何带来“维度祝福”：高维空间很多反直觉特性，使得稀疏恢复成为现实。

同时也处理带噪声的情况：观测不是严格 $\boldsymbol y = A\boldsymbol x$，而是带噪声
$$\boldsymbol y = A\boldsymbol x+\epsilon$$
此时只能稳定近似恢复，不能精确。


### 第4章 低秩矩阵恢复的凸方法
把稀疏从向量推广到矩阵。
目标：从部分观测，恢复一个低秩矩阵 $X$。

$\text{rank}(X)$ 矩阵秩，类似向量的 $\ell_0$，是非凸；
核范数 nuclear norm 是秩的凸松弛，替代 $\text{rank}$ 做优化。

应用：矩阵补全（Netflix评分，大量元素缺失）。
同样研究理论条件：什么测量下，核范数最小化能恢复真实低秩矩阵；噪声下的稳定恢复；相变现象。


### 第5章 低秩+稀疏矩阵分解：鲁棒PCA（RPCA / PCP）
现实数据矩阵 = 低秩部分 + 稀疏异常部分
$$M = L_0 + S_0$$
$L_0$：正常数据，低秩；
$S_0$：大但是稀疏的错误/异常点，比如图片里遮挡、像素损坏。

传统PCA完全扛不住大的稀疏异常；Robust PCA用凸优化把两者分开。
例子：监控视频，背景是低秩 $L$，走动的人是稀疏 $S$。


### 第6章 通用低维模型：原子范数 Atomic Norm
把稀疏、低秩统一成更一般框架：原子集合Atomic set。
稀疏、低秩只是原子范数两个特例。
同时讲凸松弛的局限性：有些结构凸松弛完全不好用，必须上非凸方法。引入高维测度集中、统计维度。


### 第7章 非凸方法处理低维模型
凸优化虽然有理论保证，但计算重；很多实际工程用非凸方法。

以前大家怕非凸：局部极小点，找不到全局最优。
这本书的重点观点：很多低维问题有特殊对称性，哪怕是非凸，梯度下降也能收敛到全局最优！
案例：相位恢复、字典学习。
字典学习：学一组基，让信号可以稀疏表示。这一章讲字典学习非凸优化。


## Part II：计算篇（第8‑9章）：大规模怎么算？
前面都是理论优化问题，现实数据百万级变量，内点法（二阶）内存爆炸，不能用。

### 第8章 凸优化的大规模算法（凸问题）
专注一阶方法（只用梯度，不用Hessian海森矩阵）：
- 近端梯度 Proximal Gradient
- Nesterov加速近端梯度 APG
- ALM 增广拉格朗日
- ADMM 交替方向乘子法

这些就是稀疏、RPCA、矩阵补全工程实现的主力算法。给出收敛理论。

### 第9章 非凸大规模优化
非凸场景怎么逃离不好的局部极小：
- 立方正则牛顿法
- 负曲率下降
- 利用问题自带对称性的迭代方法（幂迭代等）

这一章也埋下伏笔：深度网络本质就是一套大规模非凸优化。



🎯 第16章【尾声，非常关键！】低维模型通往深度学习
这一章就是你之前学习MCR²/ReduNet的原始出处！
全书前面讲的都是线性低维模型（子空间）。
真实世界图像不是严格线性子空间，而是非线性流形。

传统深度学习黑盒：拿网络+交叉熵损失，调参，但是缺少原理。
本书第16章提出：深度网络可以从低维流形表征学习的第一性原理直接推导出来，也就是MCR²最大编码率下降。

MCR²目标：最大化编码率下降，同类样本压缩，不同类拉开；
对MCR²做投影梯度上升，每一步迭代直接变成网络一层；
如果加入平移不变先验，梯度算子自动变成卷积，推导出CNN；得到ReduNet白盒网络；
**证明网络可以实现流形分类**。

这就是马毅整套工作的源头：**稀疏/低秩线性理论 → 拓展到非线性流形 → 推导出深度网络**。


# 地铁数据
地铁客流是高维时序数据（成千上万个站点、时刻、进出站记录），绝大多数场景下客流天然具备低维结构：本书中国的稀疏/低秩+MCR2表征思路，刚好用来解决地铁数据里的缺失、噪声、异常、预测，而不是单纯用LSTM、Transformer黑盒拟合。

## 一、稀疏、低秩、RPCA（线性低维框架）怎么用在地铁
地铁客流矩阵一般可以构造：
$\(M \in \mathbb R^{T\times S}\)$：行T= 时间片（5min/15min 切片)，列S= 站点；元素是该站点该时段进出站量。

#### 1.矩阵补全
地铁经常有：闸机故障、通信断连、采集丢包，产生大量缺失值。
正常工作日客流是低秩的：早高峰、完稿嗯、平峰是固定几种模式、整个矩阵秩很低。
> 方法：核范数最小化，低秩矩阵补全，比简单均值填充、线性插值靠谱很多。

#### 2.鲁棒PCA RPCA $（\(M=L+S\)）$，分离正常客流 + 异常 $\(M = L_0 + S_0\)$
- \(L_0\)：低秩，是**常态基线客流**（每天重复的早晚高峰模式）
- \(S_0\)：稀疏，是突发异常：临时限流、大型活动、事故、节假日突增
- 优势：传统PCA很容易被大客流异常点带偏；RPCA可以把异常单独拆出来，自动告警。
> 类比书中监控视频：背景 = 低秩L，走动的人 = 稀疏S；地铁里：日常基线 = L，突发扰动 = S。

#### 3.稀疏恢复（$\(\ell_1\)$凸松弛）
比如客流溯源：全网客流，**其实是少数几个“OD出行流”叠加出来的，OD流是稀疏的；观测到的是站点进站、出站（观测矩阵A），反推OD矩阵，就是典型稀疏恢复问题**。
> 局限：这是一套线性子空间假设。地铁客流会有非线性效应：节假日、天气、延时效应、换乘耦合，单纯低秩假设不够，就轮到MCR²出场。

## 二、MCR² / ReduNet 的思路对地铁数据的启示（非线性流形视角）
MCR² 核心：**寻找表征，最大化编码率下降，同类压缩、异类拉开**，迭代优化步骤 = 网络层。
放到地铁里：
- 1.地铁客流不是简单线性低秩，而是分布在**非线性流形**上：工作日、周末、节假日、暴雨天，属于流形上不同区域
  - 传统时序模型LSTM/Transformer：最小化预测误差（交叉熵/MSE），黑盒拟合；
  - MCR2思路：不是优先拟合下一刻数值，而是优先学习客流的内在压缩表征：相似的客流模式（比如周一早高峰）在表征空间聚拢，不同模式（周末、事故）互相分开。
- 2. 好处：
  - 小样本、罕见场景更稳：大型赛事、突发故障这种样本很少，MCR²靠编码压缩的第一性原理，而不是单纯靠数据拟合；
  - 表征可解释：每一层迭代对应一次编码压缩，不像Transformer是黑盒；
  - 天然适合迁移：学到城市客流底层流形结构，可以迁移到线路新开通、站点新增的场景；
- 3. 延伸
     ReduNet的梯度迭代结构，也可以用来做客流预测/分类，网络每一步都是显式的流形投影，不是无意义的非线性激活堆叠。

  方法	底层假设	地铁场景适用
低秩 / RPCA/ℓ1​	客流落在线性子空间	缺失补全、常规异常检测、OD 反推（日常平稳客流）
MCR² 表征学习	客流落在非线性流形	复杂时序、多场景（节假日 / 灾害 / 活动）、客流模式识别、小样本预测

## 四、落地提醒
1. 地铁客流有很强的周期性，线性低秩在平稳工作日效果很好，但跨场景（工作日 → 春节）会失效，这就是线性模型的边界。
2. MCR²不是拿来直接替代预测模型，它给你的是一个**表征学习目标**：你学到的表征，再喂给预测、分类、告警模块。
3. 工程上：先低成本RPCA做异常和补全（成熟、ADMM算法好实现）；再考虑MCR²做复杂模式表征，成本更高。

## 一句话总结：对地铁客流数据的启示
地铁时序客流是高维数据，**日常平稳客流具备低秩结构**，可以用本书的RPCA、核范数矩阵补全、$\(\boldsymbol{\ell_1}\)$稀疏恢复完全缺失修复、异常分离、OD流反推；但客流会受节假日、天气、突发事件影响，存在非线性，超出线性子空间假设。

**就可以借助第16章MCR²的思想：放弃单纯MSE拟合，以最大化编码率下降为目标，学习客流在非线性流形上的可压缩表征，把相似客流模式聚拢、不同模式区分开，适合罕见事件识别、小样本下的客流建模。**


# 用MCR² / ReduNet 思路做地铁数据
## 一、先把地铁数据摆进MCR²的框架

1. 样本与特征怎么构造
   
   把全网客流整理成一张样本矩阵：
   $\(X = [\boldsymbol x_1,\dots,\boldsymbol x_N] \in \mathbb R^{S\times N}\)$
   - $\(\boldsymbol x_i \in \mathbb R^S\)$：第i个时间片（如15分钟）全网$S$个站点的进出站量（或OD流量向量）；
   - $N$：时间片总数;
   - 网络学习后得到表征矩阵$\(Z = [\boldsymbol z_1,\dots,\boldsymbol z_N]\)，\(\boldsymbol z_i = f(\boldsymbol x_i)\)$
     
3. “同类/异类”在地铁里指什么
   
   MCR²的核心是同类压缩、异类拉开，地铁里的“类”可以是：
   - 有监督标签：工作日早高峰、工作日晚高峰、平峰、周末、节假日；
   - 自监督伪标签：同一客流模式加噪声、截断、局部扰动后得到的两个片段互为正样本（类似对比学习的正例对）；
   - 无监督聚类：让模型自己把客流聚拢成不同模式簇。
     
## 二、MCR²目标在地铁场景的具体含义

1.两个编码率
全体样本放在一起编码的编码率：
  $\(R(Z) = \log\det\Big(I + \frac{\gamma}{N}ZZ^\top\Big)\)$
按客流模式分 K 类，各类分别编码再加权求和：
  $\(R^c(Z) = \sum_{k=1}^K \frac{n_k}{N} R(Z_k)\)$

2.优化目标
最大化编码率下降量：
$\(\max_{\,f\,} \Delta R = R(Z) - R^c(Z)\)$
- \(R(Z)\) 尽量大：全网所有客流模式在表征空间里整体铺开，保留早晚高峰、周末、节假日等全部多样性，不要压成一团；
- \(R^c(Z)\) 尽量小：**同一类模式内部尽量挤紧、好压缩**（比如所有周一早高峰片段落在同一个低维子空间里）；
- 最终结果：不同客流模式的子空间互相正交、分得开，同类内部紧凑，不会出现神经坍塌。
  
## 三、ReduNet怎么搭：迭代一步就是一层
ReduNet不是先设计网络再配损失，而是直接对$\(\Delta R\)$做投影梯度上升，每一步更新就是网络一层：
$\(\boldsymbol z_{\ell+1} = \text{Normalize}\Big(\boldsymbol z_\ell + \eta_\ell E_\ell \boldsymbol z_\ell - \eta_\ell \sum_{k=1}^K C_\ell^k \boldsymbol z_\ell\Big)\)$

1. 两个算子在地铁里对应什么
- 扩张算子$**\(E_\ell\)**$：把全网不同客流模式整体往外拉开，避免所有模式糊在一起；
- 压缩算子$\(C_\ell^k\)$：把第 k类模式（如周末平峰）的样本往该类子空间收拢；
- 隶属度估计：用softmax估计每个样本属于哪一类模式，充当网络的非线性激活；
- Normalize：对应批量归一化（BN）。

2. 时序平移不变 → 一维卷积
   图像里“物体平移后还是同一类”推导出二维卷积；地铁时序里对应：
   > 同一种客流模式在不同时段出现，本质是时序上的平移。
   把样本做时序循环平移增广后，推导出来的 $\(E_\ell\)、\(C_\ell^k\)$ 算子自动变成**循环矩阵**，等价于**一维时序卷积**。也就是说，ReduNet 用在地铁上，天然得到一个带时序卷积结构的白盒网络，而不是手工堆 LSTM/Transformer。

3. 网络结构特点
- 残差连接：迭代式$\(\boldsymbol z_{\ell+1} = \boldsymbol z_\ell + \Delta \boldsymbol z_\ell\)$自然带出残差结构；
- 可前向构造：每一层由优化迭代显式算出，不一定依赖反向传播；
- 每一层都有明确解释：第 l 层就是第 l 轮“拉开异类、收拢同类” 的编码压缩。

## 四、具体能落地的地铁任务

1. 客流模式聚类/分类
- 无监督：最大化$\(\Delta R\)$，自动把历史客流分成早晚高峰、平峰、周末、节假日等模式簇；
- 有监督：给定模式标签，学出可分性强的表征，比直接用交叉熵更抗标签噪声；

2. 异常事件检测
- 正常客流片段会落在某一个低维类子空间内，编码代价低；
- 突发大客流（赛事、演唱会）、故障限流、极端天气导致的异常片段，不属于任何一已知低维子空间，分入各类时编码率增量大，据此触发告警；
- 工程上可先用书中主干的RPCA拆出低秩基线 L + 稀疏异常 S，再用 MCR² 学习非线性异常表征。

3. 客流预测的表征底座
- 先用MCR²学出客流的可压缩表征 $Z$，再接一个浅层预测头（线性或小型MLP）预测下一时段客流；
- 优势：罕见场景（大型活动、新线开通）样本少，靠编码压缩的第一性原理建模，比纯MSE拟合的黑盒模型更稳、更易迁移。

4. OD流表征学习
- 把全网OD流向量作为样本，MCR² 学到的表征可用于客流溯源、换乘结构分析、新线客流预估。

## 五、和传统时序模型对比

对比项	传统 LSTM / Transformer（MSE 拟合）	MCR² / ReduNet
优化目标	最小化预测误差	最大化编码率下降（同类压缩、异类拉开）
底层假设	黑盒拟合数据分布	客流分布在非线性流形上，存在可压缩低维结构
可解释性	中间层特征含义不明确	每一层对应一轮显式压缩 / 扩张迭代
