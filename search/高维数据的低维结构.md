# High‑Dimensional Data Analysis with Low‑Dimensional Models

> 作者：John Wright、马毅（Yi Ma），剑桥出版社预印本。
>  现实世界数据看着维度极高（图片、基因、视频），但数据本身藏着低维结构（稀疏、低秩）。
> 全文三大部分：原理Part I、计算Part II、应用Part III，最后尾声还把这套理论和深度学习/神经网络（MCR2、ReduNet）打通。

## 一、时代背景：从“数据少”到“数据爆炸”
1. 数据 >> 信息
2. 数据 = 有用信息 + 大量无关垃圾
3. 不完整数据 ≈ 完整信息
  比如Netflix电影评分矩阵，大量用户没看过很多电影，矩阵大量空缺；但人的喜好有很强相关性，矩阵内在秩很低，可以补全缺失评分（协同过滤）

> 核心矛盾：我们拿到的是高维原始数据，但真正的知识藏在底层低维结构中。
> 本书：（1）数学上搞清楚：什么条件下，能从高维脏数据还原底层低维结构（非渐近，给具体样本复杂度）；（2）工程上：怎么写扩展算法，大规模算出来。

### 现实世界低维结构两大主角
- 1.稀疏Sparse：一个向量绝大多数元素等于0，只有少数非零；
- 2.低秩Low-rank：矩阵的列都挤在一个很小的线性子空间。
